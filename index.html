📊 โปรแกรมวิเคราะห์ t-test และ One-way ANOVA

กรอกข้อมูล / วางจาก Excel / แนบไฟล์ Excel → กดประมวลผล → ได้ตารางสถิติแบบละเอียด คำอธิบาย และกราฟ พร้อมดาวน์โหลดเป็น Excel / PNG / Word

1เลือกวิธีการวิเคราะห์

Post-hoc (Multiple Comparisons) — กดเลือกวิธีที่ต้องการแสดง (เลือกได้หลายวิธี / ไม่เลือก = ไม่แสดง)
Tukey / Bonferroni / Scheffé / LSD ใช้เมื่อความแปรปรวนเท่ากัน • Games-Howell ใช้เมื่อความแปรปรวนไม่เท่ากัน

2ตั้งชื่อตัวแปรและป้ายกำกับกลุ่ม (Value Labels)

ชื่อตัวแปรตาม (ข้อมูลตัวเลข) — ตารางข้อมูลจะมีคอลัมน์เพิ่มตามจำนวนตัวแปร และระบบจะวิเคราะห์ให้ทีละตัวแปร
ป้ายกำกับของรหัสกลุ่ม (เช่น 1 = ชาย, 2 = หญิง) — ช่องจะเพิ่มตามรหัสกลุ่มที่พบในข้อมูลโดยอัตโนมัติ หรือกดปุ่มด้านล่างเพื่อเพิ่ม label เองได้ไม่จำกัด
พบมากกว่า 2 กลุ่ม — เลือก 2 กลุ่มที่ต้องการเปรียบเทียบด้วย t-test
